# flood-detection
A simple program that uses Google Earth Engine's satellite data to detect differences in water level.

See the project running with this link:
[Link to GEE app](https://jakesanuk.users.earthengine.app/view/jakes-flood-detection)
![Screenshot 2025-04-14 144910](https://github.com/user-attachments/assets/01913571-b45f-4ff1-bfdd-4fb34cd91423)

Blue means a water level change. 

![Screenshot 2025-04-14 144955](https://github.com/user-attachments/assets/e2efc96e-eaa8-42b2-934f-6d3ecaaa75b7)

Use the layers icon in the top-right to show and hide different layers.

<img src="https://github.com/user-attachments/assets/0d47d2d9-5962-4e3b-9301-508675acc973" width="200">


Click to select an area to view, use the sliders on the sidebar to adjust date ranges, and change the threshold value for the most accurate results.
